# NedevCode

轻量级、响应迅速的移动端代码查看、编辑与全能运行应用。

## 核心特点

- **极致轻量**：安装包体积小巧，启动飞快，专为移动端性能优化。
- **离线优先**：核心功能无需联网，随时随地在本地编写与预览代码。
- **全能环境**：内置沙盒环境，支持 HTML、JavaScript 的即时渲染与预览。
- **现代化 UI**：遵循移动端操作习惯设计，支持沉浸式状态栏与手势操作。

## 功能概览

- **专业编辑器**：支持多种编程语言语法高亮，提供智能缩进与代码补全辅助。
- **强大的项目管理**：
  - **组织有序**：支持无限层级的文件夹结构，轻松管理大型代码库。
  - **灵活操作**：支持创建、重命名、移动、压缩导出及批量删除项目。
- **深层 Git 集成**：
  - **一键克隆**：快速从 GitHub 或任何 Git 平台克隆公开/私有仓库。
  - **流畅推送**：在手机上完成修改后，可直接提交并推送到远程仓库。
- **多平台构建产物**：
  - **单文件便携版**：将整个项目打包成一个独立的 HTML 文件，无需环境即可运行。
  - **原生 Android 体验**：提供深度优化的 APK 版本，享受更好的系统集成与性能。

## 开发与构建

### 环境要求

- Node.js 22+
- npm (或 bun)

### 安装依赖

```bash
npm install
```

### 快速开始

- **启动开发服务器**：`npm run dev`
- **标准构建**：`npm run build`
- **构建单文件版**：`npm run build:single`
